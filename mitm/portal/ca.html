🔬 homelab-netsec — TLS Inspection Lab

This page is served by a Raspberry Pi running a mitmproxy lab on a network you set up. It offers a certificate that lets this Pi read the HTTPS traffic of a device that installs it — so you can study your own traffic.

⚠ Install this ONLY on a device you own and are testing.

Installing this certificate lets the machine that served this page decrypt your HTTPS. That is fine for inspecting your own device in a lab, and not something to install on anyone else's phone, or because a network "told you to." On a network you don't fully control, do not install it — close this page. (This is exactly the trick real attackers use; recognising it is part of the lesson.)

Get the CA certificate

⬇ Download for Android (.cer) ⬇ Download for iOS / laptop (.pem)

Same certificate, different formats. Never install the file that contains a private key (mitmproxy-ca.pem) — it isn't offered here.

Install & trust it

Android
  1. Download the .cer above.
  2. Settings → search “CA certificate” → Install a certificate → CA certificate.
  3. Pick the downloaded file. Accept the “network may be monitored” warning — that confirms it went into the right (CA) store, not the Wi-Fi store.
  4. Note: on Android, a user CA is trusted by browsers, not apps.
iOS / iPadOS
  1. Download the .pem; install the profile when prompted.
  2. Settings → General → VPN & Device Management → install the profile.
  3. Settings → General → About → Certificate Trust Settings → enable full trust for the mitmproxy cert.
Laptop (Windows / macOS / Linux)
  1. Download the .cer/.pem and import it into the OS/browser trusted root store.

To stop trusting it later, remove it from the same place you installed it (Trusted credentials → User, or Certificate Trust Settings).
