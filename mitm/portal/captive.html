📶 Welcome to the Lab Wi-Fi

This is a security-training access point — not a public or commercial network, and not affiliated with any brand.

You didn't type this address. The network forced this page onto your device the moment you connected, and until you tap the button below nothing else will load. That is exactly how café / hotel / airport Wi-Fi — and a rogue "evil-twin" network — takes control of what you see first.

Optional, and kept only in this browser — it is not sent anywhere and not stored on the server. This lab collects no login details at all. Leave it blank if you like.

⚠ The lesson: a network that greets you like this can decide what page you see, watch which sites you visit, and (on open Wi-Fi) read unencrypted traffic. It should never ask for a password to another account, nor ask you to install a certificate/profile to get online — those are the red flags of a network trying to manipulate you.
